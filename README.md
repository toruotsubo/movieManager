# Movie Manager

Electron と Next.js (App Router) を活用した、ローカル動画ファイルの管理用デスクトップアプリケーションです。

---

## 📖 概要

Movie Manager は、PC 内の動画ファイルをデータベース（ローカルJSONストレージ）上でメタデータ管理し、直感的な UI で閲覧・評価・整理ができるデスクトップアプリです。

- **動画データ本体は保持せず、参照パスのみを管理**します。
- 動画ファイルに直接メタデータを書き込むことはありません。
- 初回起動時やドロップ時に自動でスクショサマリー画像（720px × 405px）を作成します。
- OS デフォルトの動画プレイヤーと連携して再生します。

## 🌟 主な機能

### 1. 3つのメイン画面構成
- **キー項目一覧画面 (`#{キー項目名}一覧`)**
  - ユーザー定義キー項目ごとにグループ化された一覧表示。
  - 各キー項目ごとの評価変更・即時反映およびソート機能。
  - 高評価動画の自動サマリー画像サムネイル表示。
  - キー項目専用「タグ」による絞り込み機能（タグドロップダウン & タグチップ連携）。
  - 各キー項目アイテムの「編集」ボタンからキー項目フォームモーダルを呼び出し。
- **動画一覧画面**
  - キー項目一覧画面からの遷移時、選択されたキー項目による自動絞り込み。
  - 動画詳細画面への遷移・復帰後もキー項目絞り込み状態を完全保持。
  - タイトル、カテゴリ、主演（ふりがな考慮）、公開年月日、評価によるソート機能。
  - サムネイルクリックで OS デフォルトの動画プレイヤー起動。
- **動画詳細画面**
  - 各動画のメタデータ、評価、コメント等の詳細表示。
  - 評価の即時変更（星5段階評価）。

### 2. モーダル機能
- **キー項目フォームモーダル (新機能)**
  - 各キー項目カードの「編集」ボタンから開く専用フォーム。
  - 「主演（ふりがな）」およびキー項目専用「タグ」の編集。
  - 「主演（ふりがな）」変更時、そのキー項目に紐づくすべての動画データの `cast_kana` に自動で一括反映。
- **設定モーダル**
  - ユーザー定義項目（最大3つ）の項目名設定。
  - キー項目の選択・変更。
  - データ初期化機能。
- **項目入力フォームモーダル**
  - アプリへの動画ファイルのドラッグ＆ドロップ時に自動トリガー。
  - サマリー画像のプレビュー・動画プレイヤー操作による任意フレームのスクショ指定保存。
  - 動画情報の編集および削除。

## 🚀 開発環境のセットアップと起動方法

### 前提条件
- **Node.js**: v18 以降推奨
- **npm** (または yarn / pnpm)

### インストール
```bash
npm install
```

### 開発モードで起動
Next.js 開発サーバーと Electron メインプロセスを並行して起動します。

```bash
npm run dev
```

### アプリのビルド & パッケージング
プロダクション用ビルドを行い、インストーラー/実行ファイルを作成します。

```bash
npm run build
```

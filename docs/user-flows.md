# User Flows

## 1. 動画を登録する

### 概要

ユーザーが動画ファイルをアプリに登録する

### Flow

1. ユーザーがアプリに動画データをドロップする
2. ファイルを読み込む
3. 動画の基本情報（動画の長さ、動画サイズ、フレームレート、ファイルサイズ）を取得する
4. 動画の中間時点からサマリー画像を作成する
5. 項目編集モーダルを表示する
6. ユーザーがタイトルや各項目、評価、タグなどを入力する
7. ユーザーが「保存」をクリックする
8. データを保存する
9. 動画一覧画面に戻る

### User Actions

- サマリー画像を変更できる
- 各項目を入力できる
- 登録をキャンセルできる

### Error Cases

#### 対応していないファイル

対応していない形式のファイルを選択した場合、

「このファイル形式には対応していません」

と表示する。

登録処理は開始しない。

#### ファイル読み込み失敗

ファイルの読み込みに失敗した場合、

「動画を読み込めませんでした」

と表示する。

登録処理は開始しない。

#### 保存失敗

保存に失敗した場合、

「動画を保存できませんでした」

と表示する。

入力内容は保持し、ユーザーが再試行できるようにする。

### Success Criteria

- 入力した項目データが保持される

## 2. 動画を再生する

### Flow

1. ユーザーが動画一覧画面または動画詳細画面でサマリー画像をクリックする
2. OS標準の動画プレーヤーを起動する

## 3. 動画データを削除する

### Flow

1. ユーザーが動画詳細画面で「削除」をクリックする
2. 確認ダイアログを表示する
3. ユーザーが「削除」を選択する
4. 動画を削除する
5. 動画一覧画面に戻る

### Confirmation

確認ダイアログには以下を表示する。

> この動画を削除しますか？

「キャンセル」と「削除」の2つのボタンを表示する。

### Rules

- 「キャンセル」をクリックした場合、何も変更しない
- 削除後は動画一覧に戻る
- 削除した動画は検索結果にも表示しない

### Error Cases

削除に失敗した場合、

「動画を削除できませんでした」

と表示する。

動画詳細画面はそのまま維持する。
